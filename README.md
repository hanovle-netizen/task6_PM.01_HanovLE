# ВелосипедДрайв — ДЭ 09.02.07-2-2026, вариант 2, модули 3–4

Продолжение л/р 5 (модули 1–2): добавление, редактирование и удаление товаров, работа с заказами.

- `Database/BikeDrive.sql` — скрипт БД MS SQL Server (схема в 3НФ + данные; у товара добавлен ProductId).
- `BikeDrive/` — исходный код приложения (WPF, .NET 8, Entity Framework Core).
- `Release/` — исполняемые файлы (framework-dependent, нужен .NET 8 Desktop Runtime).
- `Docs/` — ER-диаграмма (PDF), отчёт со скриншотами, `screens/`.

## Что добавлено
- Форма добавления/редактирования товара: все поля, проверки ввода, фото с уменьшением до 300×200, ID = MAX + 1.
- Только одно окно редактирования одновременно; удаление товара запрещено, если он есть в заказах.
- Окно «Заказы» (менеджер — просмотр, администратор — добавление, редактирование, удаление).
- Кнопки «Назад», заголовки окон, сообщения об ошибках и подтверждения удаления.

## Запуск
1. Выполнить `Database/BikeDrive.sql` на SQL Server.
2. В `BikeDrive/appsettings.json` (или `Release/appsettings.json`) указать строку подключения.
3. Запустить `BikeDrive.exe`.
